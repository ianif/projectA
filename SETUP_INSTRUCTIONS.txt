2. PROJECT OVERVIEW
================================================================================

This is a professional gynecologist clinic website with the following features:
- Responsive design (works on desktop, tablet, mobile)
- Complete in Greek language
- Four main sections:
  * Αρχική (Homepage) - Welcome and hero section
  * Βιογραφικό (Biography) - Doctor profile and credentials
  * Υπηρεσίες (Services) - Medical services offered
  * Επικοινωνία (Contact) - Contact form and information

Technology Stack:
- HTML5 (semantic markup)
- CSS3 (responsive design, gradients, animations)
- Vanilla JavaScript (no external dependencies)
- SVG Images (scalable vector graphics)

4. INSTALLATION & SETUP
================================================================================

STEP 1: Download/Extract the Project
--------------------------------------
1. Extract the project folder to your desired location
   Example: C:\Users\YourName\Desktop\dr-kourletakis-website
   Example: /home/username/Documents/dr-kourletakis-website
   Example: /Users/username/Documents/dr-kourletakis-website

2. Ensure all files are present:
   - index.html
   - styles.css
   - script.js
   - generate_images.py
   - test_website.py
   - SETUP_INSTRUCTIONS.txt
   - TESTING_AND_BENCHMARKING.txt
   - README.md
   - images/ folder with SVG files

STEP 2: Verify Image Files (Optional)
--------------------------------------
If SVG images are missing, regenerate them using Python:

For Windows:
  1. Open Command Prompt in the project directory
  2. Run: python generate_images.py
  3. Wait for completion message

For macOS/Linux:
  1. Open Terminal in the project directory
  2. Run: python3 generate_images.py
  3. Wait for completion message

The script will create all necessary SVG image files in the images/ folder.

STEP 3: No Further Installation Required
-----------------------------------------
The website is ready to use! No npm, pip, or other package installation needed.

5. RUNNING THE WEBSITE LOCALLY
================================================================================

OPTION A: Using Python (Recommended - Easiest)
-----------------------------------------------

For Windows:
1. Open Command Prompt (cmd.exe)
2. Navigate to the project folder:
   cd C:\path\to\dr-kourletakis-website
3. For Python 3.6+, run:
   python -m http.server 8000
4. Open your browser and visit: http://localhost:8000
5. You should see Dr. Kourletakis's website

For macOS/Linux:
1. Open Terminal
2. Navigate to the project folder:
   cd /path/to/dr-kourletakis-website
3. For Python 3.6+, run:
   python3 -m http.server 8000
4. Open your browser and visit: http://localhost:8000
5. You should see Dr. Kourletakis's website

OPTION B: Using Node.js (if installed)
---------------------------------------
1. Open Terminal/Command Prompt
2. Navigate to the project folder
3. Run: npx http-server
4. Open browser to: http://localhost:8080

OPTION C: Using Live Server (VSCode extension)
-----------------------------------------------
1. Install VSCode
2. Install "Live Server" extension (by Ritwick Dey)
3. Right-click index.html
4. Select "Open with Live Server"
5. Website opens automatically

OPTION D: Using Your Browser Directly (Limited functionality)
--------------------------------------------------------------
1. Open file manager
2. Navigate to the project folder
3. Right-click on index.html
4. Select "Open with" → your web browser
5. Note: Some JavaScript features may not work due to CORS restrictions

IMPORTANT: Recommended Method
The Python HTTP server (Option A) is recommended for full functionality.

6. TROUBLESHOOTING
================================================================================

PROBLEM: "HTTP 404 - Not Found" error
SOLUTION:
- Verify you're in the correct project directory
- Ensure all files are present
- Try a different port: python -m http.server 9000
- Clear browser cache (Ctrl+Shift+Delete)

PROBLEM: Images not loading
SOLUTION:
- Verify images/ folder exists
- Regenerate images: python generate_images.py
- Check browser console (F12) for error messages
- Ensure image file extensions are correct (.svg)

PROBLEM: Form doesn't submit
SOLUTION:
- Check browser console for JavaScript errors (F12)
- Ensure JavaScript is enabled
- Try a different browser
- Clear browser cache and cookies

PROBLEM: Styling looks broken
SOLUTION:
- Press F5 to refresh page
- Press Ctrl+Shift+Delete to clear cache
- Try a different browser
- Check if all CSS rules loaded in DevTools

PROBLEM: Greek text appears as squares/symbols
SOLUTION:
- Verify UTF-8 encoding in browser (View → Encoding → UTF-8)
- Check HTML meta charset tag: <meta charset="UTF-8">
- Update browser to latest version
- Try a different browser

PROBLEM: Website doesn't respond to clicks
SOLUTION:
- Check if JavaScript is enabled (Settings → Privacy → JavaScript)
- Verify script.js loads (DevTools → Console)
- Try clearing browser cache
- Restart browser

PROBLEM: "Address already in use" error
SOLUTION:
- Port 8000 is already running something
- Try different port: python -m http.server 9000
- Visit: http://localhost:9000
- Or kill existing process using port 8000

PROBLEM: Cannot find Python
SOLUTION:
- Verify Python is installed: python --version
- If not installed, download from python.org
- Make sure "Add Python to PATH" was checked during installation
- Use full path: C:\Python\python.exe -m http.server

GENERAL TIPS:
1. Always check browser console (F12) for errors
2. Try incognito/private browsing mode
3. Disable browser extensions temporarily
4. Try a different browser
5. Restart your computer if needed
