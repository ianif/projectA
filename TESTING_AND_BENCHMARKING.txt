1.1 MINIFICATION (Optional Production Step)
---------------------------------------------

What is minification?
- Removes unnecessary characters from code without changing functionality
- Reduces file sizes (typically 20-40% reduction)
- Used for production deployment

OPTION A: Online Tools (No Installation Required)
1. CSS Minification:
   - Visit: https://cssminifier.com/
   - Copy contents of styles.css
   - Paste into the tool
   - Copy minified output
   - Save as styles.min.css

2. JavaScript Minification:
   - Visit: https://javascript-minifier.com/
   - Copy contents of script.js
   - Paste into the tool
   - Copy minified output
   - Save as script.min.js

OPTION B: Using Node.js (Requires npm)
1. Install minification tools:
   npm install -g terser cleancss-cli

2. Minify CSS:
   cleancss styles.css -o styles.min.css

3. Minify JavaScript:
   terser script.js -o script.min.js

4. Update index.html to use minified files:
   <link rel="stylesheet" href="styles.min.css">
   <script src="script.min.js"></script>

OPTION C: Using Python (Requires Python 3.6+)
A simple Python script for minification:

  python3 -c "
import re
import sys

# Read CSS
with open('styles.css', 'r') as f:
    css = f.read()
css_min = re.sub(r'/\*.*?\*/', '', css, flags=re.DOTALL)
css_min = re.sub(r'\s+', ' ', css_min)
css_min = re.sub(r':\s+', ':', css_min)
with open('styles.min.css', 'w') as f:
    f.write(css_min)
print('✓ CSS minified: styles.min.css')
  "

5.2 STRESS TESTING WITH PYTHON
-------------------------------

Create stress_test.py:

  import concurrent.futures
  import requests
  import time
  
  url = "http://localhost:8000"
  num_requests = 100
  concurrent_users = 10
  
  def make_request(i):
      try:
          start = time.time()
          resp = requests.get(url, timeout=10)
          elapsed = time.time() - start
          return (resp.status_code, elapsed)
      except Exception as e:
          return (0, 0)
  
  start_time = time.time()
  with concurrent.futures.ThreadPoolExecutor(max_workers=concurrent_users) as executor:
      results = list(executor.map(make_request, range(num_requests)))
  total_time = time.time() - start_time
  
  successful = sum(1 for code, _ in results if code == 200)
  avg_response = sum(t for _, t in results) / len(results)
  
  print(f"Requests: {num_requests}")
  print(f"Successful: {successful}")
  print(f"Failed: {num_requests - successful}")
  print(f"Avg Response Time: {avg_response*1000:.2f}ms")
  print(f"Total Time: {total_time:.2f}s")

Run it:
  python3 stress_test.py

Expected Results:
  Successful: ~100
  Avg Response Time: < 100ms
  Total Time: < 5s

10. TROUBLESHOOTING TEST ISSUES
================================================================================

10.1 TEST SCRIPT FAILS
----------------------

Issue: "python: command not found"
Solution: 
  - Use "python3" on macOS/Linux
  - Install Python from python.org on Windows
  - Add Python to PATH

Issue: "Module not found"
Solution:
  - All modules are stdlib, no installation needed
  - Verify Python version: python --version (3.6+)

Issue: "Permission denied"
Solution (macOS/Linux):
  - Make script executable: chmod +x test_website.py
  - Run with python3: python3 test_website.py

10.2 FILE NOT FOUND ERRORS
--------------------------

Issue: Tests report missing files
Solution:
  - Verify project structure with: ls -la (macOS/Linux)
  - Check file extensions (should be .html, .css, .js, .svg)
  - Move to correct directory before running tests

10.3 FORM VALIDATION FAILS
--------------------------

Issue: Form validation test fails
Solution:
  - Ensure script.js is present and linked
  - Check for JavaScript errors: Open DevTools Console (F12)
  - Verify form has id="contactForm"
  - Check all form fields have correct IDs

10.4 PERFORMANCE TESTS SLOW
---------------------------

Issue: Benchmarks show slow performance
Solution:
  - Close other browser tabs
  - Disable browser extensions
  - Close other applications
  - Try again on idle system
  - Check system RAM/CPU usage

10.5 RESPONSIVE DESIGN NOT WORKING
----------------------------------

Issue: Media queries not applying
Solution:
  - Verify CSS file is linked: <link rel="stylesheet" href="styles.css">
  - Check file size (should be 15-20KB)
  - Clear browser cache: Ctrl+Shift+Delete
  - Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R)
